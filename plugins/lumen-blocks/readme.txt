ルーメン株式会社（架空）サイト用のカスタムブロック集と「導入事例」投稿タイプ。ポートフォリオ用デモです。

== Description ==

* ヒーロー / サービスカード / 実績・数字（カウントアップ） / 導入事例一覧（動的） / FAQ（アコーディオン） / CTAバナー
* 投稿タイプ「導入事例（works）」、タクソノミー「事例カテゴリー」、投稿メタ（クライアント・成果・支援期間）
* WP-CLI: `wp lumen-demo import` でデモコンテンツを投入（Lumen テーマ有効化後に実行）

ソースコード（React / @wordpress/scripts）: https://github.com/minatofullstack-ops/wp-react-blocks-demo
